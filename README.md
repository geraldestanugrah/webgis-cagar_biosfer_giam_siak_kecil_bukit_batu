# webgis-cagar_biosfer_giam_siak_kecil_bukit_batu
Cagar Biosfer Giam Siak Kecil–Bukit Batu - WebGIS yang berisi informasi tutupan lahan dengan 7 kelas (Hutan, Semak belukar, Kelapa sawit, Hutan tanaman, Lahan terbuka, Lahan terbangun, dan Badan air) kemudian fragmentasi lanskap (Patch Density, Edge Density, Aggregation Index), serta NDMI, dan LST
